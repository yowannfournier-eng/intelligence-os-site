Portée

Cette politique décrit le site de présentation Intelligence OS Automation. Le site statique ne comporte ni compte utilisateur, ni formulaire, ni outil de suivi ajouté par le projet.

Données Google et automatisations

Les fonctions de gestion de Google Apps Script nécessitent une autorisation distincte du titulaire du compte Google. Une fois activées, ces fonctions peuvent accéder aux ressources indiquées sur l'écran de consentement, afin de modifier le code du script choisi. La présente page n'active ni ne collecte elle-même ces autorisations.

Hébergement et tiers

Le site peut être hébergé par GitHub Pages. GitHub peut traiter des informations techniques de visite conformément à ses propres politiques. Les autorisations des outils de développement sont gérées séparément par Google et GitHub.

Conservation et retrait

Le propriétaire peut retirer les accès Google accordés à l'application dans les paramètres de sécurité de son compte Google. Les journaux ou données éventuellement traités par le système automatisé nécessitent des règles de conservation distinctes, à documenter avant la mise en production.
